# Blueprint Docs

Folder ini untuk dokumen rancangan teknis dan arsitektur.

## Isi utama

- `migration/`: blueprint migrasi, matriks, status eksekutif, dan laporan detail migrasi.
- `systems/`: peta komponen, inventory app/widget, route inventory, dan changelog shadow.
- `data/`: data sumber untuk dashboard/analitik.
- `sql/`: query SQL paket analitik.

## Format rekomendasi

- Gunakan `MD` sebagai format utama blueprint (mudah versioning dan review).
- Gunakan `HTML/PDF` hanya untuk versi presentasi atau distribusi formal.
