# Struktur Dokumentasi Lawangsewu

Dokumentasi kini dirapikan menjadi 3 folder utama:

1. `blueprint/`
   Isi: arsitektur, migration plan, peta sistem, data, dan SQL.
   Format utama: `MD`.

2. `panduan/`
   Isi: panduan admin/operator, security guide, referensi operasional, walkthrough landing.
   Format utama: `MD`, dengan `HTML` untuk portal/index.

3. `laporan/`
   Isi: laporan final dan laporan bulanan.
   Format wajib: `PDF`.

Catatan:
- Folder kompatibilitas (`appendix/`, `root/`, dan beberapa file HTML di level `docs/`) dipertahankan sebagai tautan/symlink agar rute lama tetap berjalan.
