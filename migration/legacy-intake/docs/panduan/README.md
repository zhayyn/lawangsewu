# Panduan Admin Dan Operator

Folder ini untuk panduan operasional, SOP, hardening, dan handbook baca.

## Isi utama

- `admin-operator/`: indeks dokumen resmi, guide baca, quick start, deployment status, dan audit konsolidasi.
- `appendix/security/`: panduan keamanan operasional.
- `appendix/wa-caraka/`: panduan WA Caraka dan dokumen pendukung operasional.
- `appendix/reference/`: register capability dan dokumen referensi.
- `walkthrough/`: landing publik dokumentasi.

## Format rekomendasi

- Gunakan `MD` untuk panduan admin/operator agar mudah dirawat.
- Gunakan `HTML` hanya untuk indeks/portal baca cepat.
