# 🚀 Lawangsewu Portal - Quick Start Guide

## Getting Started

### 1️⃣ **Access the Portal**

Open your browser and go to:
```
https://lawangsewu.pa-semarang.go.id
```

**What happens next:**
- If you're **already logged in** → You'll automatically go to the Dashboard
- If you're **not logged in** → You'll be taken to the Login page

---

## 2️⃣ **Login to Portal**

### On the Login Page:
1. Enter your **Username**
2. Enter your **Password**
3. Click the **"Masuk" (Login)** button

**After successful login:**
✅ You'll see the main Dashboard with 3 new buttons
✅ You can now access Blasting, Pengaduan, and Konsultasi modules

**If login fails:**
❌ You'll see an error message like "Username atau password salah"
❌ Check your username and password, then try again

---

## 3️⃣ **Dashboard Overview**

Once logged in, you'll see the main dashboard with:

### 📢 **Blasting Module** (Admin Only)
- **Purpose:** Send messages to many people at once via WhatsApp
- **Use it for:** Announcements, alerts, bulk communications
- **Access:** Click the yellow "📢 Blasting" button
- **How to use:**
  1. Click "Create New Batch"
  2. Upload a CSV file with phone numbers
  3. Enter your message
  4. Click "Send" to start the blast
  5. Monitor progress with real-time status updates

### 📩 **Pengaduan Module** (Admin & Operator)
- **Purpose:** Receive and manage complaints from the public
- **Use it for:** Customer service, issue tracking, complaint resolution
- **Access:** Click the red "📩 Pengaduan" button
- **How to use:**
  1. You'll see complaints organized in tabs:
     - "Masuk" = New complaints
     - "Diproses" = Being handled
     - "Selesai" = Resolved
     - "Ditolak" = Rejected
  2. Click on a complaint to view details
  3. Click "Reply via WA" to send a response
  4. Change the status as you process it

### 💬 **Konsultasi Module** (Admin & Operator)
- **Purpose:** Answer questions from the public
- **Use it for:** Q&A sessions, public inquiries, information requests
- **Access:** Click the blue "💬 Konsultasi" button
- **How to use:**
  1. You'll see questions organized in tabs:
     - "Open" = New questions
     - "Aktif" = Being answered
     - "Selesai" = Answered
     - "Ditutup" = Closed
  2. Click on a question to view the details
  3. Click "Answer" to provide your response
  4. Click "Send & Auto-Close" to send and close automatically
  5. Or click "Send & Active" to keep it open for follow-up

---

## 4️⃣ **Common Tasks**

### How to Send a Blast (📢 Blasting)

**Step-by-step:**
1. Go to Dashboard → Click "📢 Blasting"
2. Click "Create New Batch"
3. Prepare a CSV file with phone numbers (one per line):
   ```
   62812345678
   62887654321
   62812345679
   ```
4. Select the file and upload
5. Enter your message (e.g., "Selamat datang di portal kami!")
6. Click "Send Blast"
7. Wait while the system sends to all numbers
8. Check the status page to see results

---

### How to Reply to a Complaint (📩 Pengaduan)

**Step-by-step:**
1. Go to Dashboard → Click "📩 Pengaduan"
2. Click the "Masuk" tab to see new complaints
3. Click on a complaint to open it
4. Read the sender's message
5. Click "Reply via WA" button
6. Type your response message
7. Select new status:
   - "Diproses" = I'm working on it
   - "Selesai" = Problem solved
   - "Ditolak" = Can't help / Won't help
8. Click "Send Reply"
9. The message will be sent to the complainant via WhatsApp

---

### How to Answer a Question (💬 Konsultasi)

**Step-by-step:**
1. Go to Dashboard → Click "💬 Konsultasi"
2. Click the "Open" tab to see new questions
3. Click on a question to read it
4. Click "Answer" button
5. Type your answer
6. You have two options:
   - **"Send & Auto-Close"** = Send answer and close the session
   - **"Send & Active"** = Send answer and stay open for more questions
7. Press the button you want

## 6️⃣ **Help & Support**

### If something isn't working:

1. **Can't login?**
   - Double-check your username and password
   - Make sure CAPS LOCK is off
   - Try another browser
   - Clear your browser cache

2. **Module is slow?**
   - Wait a few seconds, the system might be processing
   - Refresh the page (F5 key)
   - Check if your internet connection is stable

3. **Message didn't send?**
   - Check the phone number format (start with 62)
   - Verify the number's WhatsApp account exists
   - Check the error message for details

4. **Can't see a module?**
   - You might not have permission (contact Admin)
   - Try logging out and back in
   - Check your user role
   
5. **Still stuck?**
   - Contact your administrator
   - Provide error message details
   - Note: Use the message that appears on screen

## 9️⃣ **FAQ - Frequently Asked Questions**

**Q: Can I send messages to more than 500 people at once?**  
A: The limit is 500 recipients per batch. You can create multiple batches for more.

**Q: What phone number format should I use?**  
A: Use Indonesian format: `62` (replace 0 prefix) + number  
Example: `0812-1234-5678` → `62812345678`

**Q: Can I schedule messages for later?**  
A: Not yet - messages send immediately. This feature may be added later.

**Q: How long does a blast take?**  
A: Depends on number of recipients. Usually 1-2 seconds per message. 500 numbers ≈ 15-20 minutes.

**Q: What if a number fails?**  
A: The system will retry automatically. Check the failure reason in the job details.

**Q: Can I edit a message after sending?**  
A: No - WhatsApp messages can't be edited. You can only send a follow-up message.

**Q: How do I know if my message was delivered?**  
A: Check the blast job status page. It shows sent/failed counts.

**Q: Can operators do everything admins can?**  
A: No - Operators can only use Pengaduan & Konsultasi. Only Admins can use Blasting.

**Q: What if I accidentally send to wrong number?**  
A: You can't unsend via the portal, but you can send a follow-up correction message.
